## Reading the matrix

- **Every pick is production-grade** and credible from at least **Startup through Enterprise**; the genuinely universal ones (Postgres, FastAPI, Next.js, Redis, AWS, GitHub Actions, Secrets Manager) reach **Fortune 500**.
- **13 / 22 close a named skill-gap** from the career assessment — the reason this build converts into a portfolio asset, not just a working app.
- **Only two decisions are HARD to reverse** (Qdrant load #2, embedding dimension #5) — both de-risked by the **same-dimension pin + a `VectorStore` interface**, turning a re-embed into a re-index.
- **The Fortune-500 ceiling** on a few rows (multi-agent, Auth0, hosted serving, multi-region failure-handling) is exactly the *operational* gap the career assessment says portfolios can't fully close — it needs real production traffic, not more architecture.
