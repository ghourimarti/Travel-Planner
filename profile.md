## 3. PCB Fault Detection with a Vision-Language Model

*Electronics-manufacturing QA use case*

Built a multimodal fault-analysis tool on **Qwen2-VL-2B-Instruct** that takes a PCB image plus a natural-language prompt ("identify what's wrong with this board," "explain this trace burn") and returns an engineering-level description of the fault and a suggested fix. Images are pre-processed with Pillow / OpenCV; the model is served on GPU through a FastAPI inference endpoint with domain-specific prompt templates; generation is length-capped for precise, structured output. Designed to triage solder bridging, cold joints, open circuits, and missing components from a single photo and explain them in plain language.

**Stack:** Qwen2-VL-2B-Instruct · Hugging Face Transformers + AutoProcessor · PyTorch (CUDA) · Pillow / OpenCV · FastAPI

## 4. Radiology Report Generation with MAIRA-2

*Clinical-imaging research demo*

Built a Gradio application that runs Microsoft's **MAIRA-2** multimodal model on frontal and lateral chest-X-ray pairs together with clinical-indication text to generate radiology-style findings. Uses the official MAIRA-2 AutoProcessor to align image and text inputs and serves dynamically on GPU/CPU with token-aware decoding.

*Honest status: a working interface demo on public / sample images — not validated against real clinical ground truth and not a clinical-grade or compliance-deployed system.* **Stack:** MAIRA-2 · PyTorch · Hugging Face Transformers · Gradio

## 5. Sales-Call Intelligence Platform

*SaaS sales-enablement use case*

Built a Streamlit application that turns sales-call recordings into structured coaching insight. Audio is transcribed with Whisper; an LLM then extracts sentiment, objections, talk/listen ratio, competitor mentions, and next-step alignment, and produces a per-rep scorecard plus a trend dashboard. Call metadata is stored in PostgreSQL; the app is containerized with Docker and runs on AWS EC2 with S3 for audio storage. Built to replace inconsistent manual call QA with repeatable, automated scoring.

**Stack:** Streamlit · OpenAI Whisper · GPT / LLM APIs · Pandas / Matplotlib · PostgreSQL · Docker · AWS EC2 + S3
